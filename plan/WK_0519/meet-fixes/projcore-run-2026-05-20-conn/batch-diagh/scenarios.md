# Batch DIAGH Scenarios

## DR-23 Room-Name Search

1. Rooms search input is visible on the rooms list page.
2. Search filters by room title using a case-insensitive substring.
3. Search spans all pages, not only currently rendered rows.
4. Empty search restores the full paginated room list.
5. Search keeps DR-14 clickable rows, DR-15 slug join links, DR-16 open/close controls, and pagination behavior intact.
