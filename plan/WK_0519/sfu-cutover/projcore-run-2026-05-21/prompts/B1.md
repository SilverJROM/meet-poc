## Task (SR-1) — server-side proxy to Cloudflare Realtime SFU
Create `backend/src/modules/realtime-sfu/` that wraps the Cloudflare Realtime HTTP API. Base URL `https://rtc.live.cloudflare.com/v1/apps/${SFU_APP_ID}`. Auth header `Authorization: Bearer ${SFU_TOKEN}` — injected server-side; the App Secret MUST NEVER appear in any response to the browser.

**Wrap these CF endpoints (server-side fetch):**
- `POST /sessions/new` → returns `{ sessionId }`.
- `POST /sessions/{sessionId}/tracks/new` → publish (local) or subscribe (remote) tracks; pass through the body (sessionDescription + tracks[]) and the CF response (which may include `requiresImmediateRenegotiation` + an offer SDP).
- `PUT /sessions/{sessionId}/tracks/update` → layer/transceiver updates (needed by B6b).
- `PUT /sessions/{sessionId}/renegotiate` → submit the client's answer SDP.
- `PUT /sessions/{sessionId}/tracks/close` → close tracks by mid (support `force` flag).
- `GET /sessions/{sessionId}` → session state.

**Frontend-facing routes** (register in server.ts), each requiring an authenticated + ADMITTED member of the relevant room (reuse the existing auth + signaling/admitted membership check — same gate as DR-41 diagnostics posting) AND resource-ownership (a caller may only operate on a session it owns / subscribe within its admitted room — track caller→sessionId ownership server-side; reject foreign session mutation):
- `POST /api/sfu/session`
- `POST /api/sfu/tracks`
- `PUT  /api/sfu/tracks/update`
- `PUT  /api/sfu/renegotiate`
- `PUT  /api/sfu/tracks/close`
- `GET  /api/sfu/session/:id`

**Error contract:** on CF 4xx/5xx, pass through a clean error shape (status + CF errordescription) WITHOUT leaking the token or internal detail. Config-driven base URL (constant/env, default the CF base). Read SFU_APP_ID/SFU_TOKEN defensively (if missing, the routes return a clear 503 "SFU not configured" rather than crashing).
